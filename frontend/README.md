# Böblingen Spediteur — Logistik- und Routenmanagement-Modul

Ein innovatives Full-Stack-Webanwendungsprojekt zur Visualisierung und Steuerung von Logistikprozessen in Echtzeit. Entwickelt als Teil der Cloud Collar Systemlandschaft (Warehouse OS / Control Panel).

## 🚀 Features
* **Echtzeit-Routenverfolgung:** Interaktive Karte mit Live-Anzeige von LKW-Bewegungen und Routenplanung (Vite + React + Leaflet/Map-Komponenten).
* **Asynchroner Backend-Server:** Effiziente Statusverwaltung (IDLE, DELIVERED) und API-Verarbeitung mittels Python und `asyncio`.
* **Modulare Architektur:** Saubere Trennung zwischen einem performanten React-Frontend und einem schnellen Python-Backend.

## 🛠️ Technologien
* **Frontend:** React, Vite, JavaScript, CSS3, HTML5
* **Backend:** Python, Asynchrone Programmierung (`asyncio`), REST API
* **Deployment & Hosting:** Vercel (Frontend), Render (Backend)

## 📂 Projektstruktur
* `/frontend` — Die Client-Anwendung (React + Vite)
* `main.py` — Der Python-Backend-Server
* `requirements.txt` — Python-Abhängigkeiten
